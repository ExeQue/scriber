# Several documents

Scriber opens each document in its own **tab** above the canvas.

- The tab shows the file name, with • when there are unsaved changes. Hover for the full path.
- **+** or <kbd>Ctrl+N</kbd> opens a new, empty document with the current material size.
- <kbd>Ctrl+O</kbd> opens a file in a new tab. If the file is already open, Scriber shows that tab.
- <kbd>Ctrl+Tab</kbd> and <kbd>Ctrl+Shift+Tab</kbd> switch tabs.
- ✕, a middle-click or <kbd>Ctrl+W</kbd> closes a tab. With unsaved changes it asks: Save, Don't
  save or Cancel.

Each tab keeps its own undo, selection, layers, comments, constraints, machine and material, zoom
and position. The material library is shared by all tabs.

**File → Open recent** lists the last 10 files. When you quit, Scriber remembers which files were
open and opens them again next time (unless you start it with a file, or turned that off in Edit →
Settings… → Files, where you can also clear the recent list). Quitting with unsaved tabs
asks once: Save all, Don't save or Cancel.

AI agents work on the active tab unless they name another document; see
[How agents work with Scriber](../agents/working-with-agents).
